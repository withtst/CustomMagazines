## JWebP 0.2.0

The Java helper bundles the core decoder from JWebP 0.2.0 (`org.glavo.webp`) to read WebP files. It is a pure Java decoder supporting lossy, lossless, and animated WebP; the reader displays the first frame of an animated file.
